# Grouped Normal terms from per-group statistics: gradient, build and rebind, many-term, plain-family and whole-fit timings
# Model name: AMD Ryzen 9 5900X 12-Core Processor; Linux 6.18.58-1-lts; rustc 1.89.0; 2026-10-27
# Base: main at a1e36fc (#48's fused loops). This branch: 28bbfcf (perf/grouped-one-pass).
# The base build is `git archive a1e36fc` built in a scratch directory with its own target
# directory and its own wheel. Its rust_core/examples/indexed_gradient_cost.rs was replaced by
# this branch's copy, which adds the build and rebind columns and uses only public API that
# main has, so both builds time the same program. grouped_scaling.rs, gradient_cost.rs and
# benchmarks/grouped_normal_fits.py are unchanged between the two revisions.
# Every run held /tmp/claude-1000/bench.lock and started at a 1-minute load below 1.5 (printed
# per run, 1.02 to 1.47). Builds alternate, and every group of runs was repeated with builds
# and shapes in the reverse order ("order B"). Commands, per build:
#   target/release/examples/indexed_gradient_cost 500:20 5000:100 200:5000   (and reversed)
#   target/release/examples/grouped_scaling 10 100 1000                       (and reversed)
#   target/release/examples/gradient_cost 500 ; gradient_cost 5000
#   PYTHONPATH=<build>/.pybuild python benchmarks/grouped_normal_fits.py <build> ROWS GROUPS
# Other processes shared the machine during the session (the 1-minute load reached several
# hundred two hours before these runs); the load gate is the only control for that.
#
