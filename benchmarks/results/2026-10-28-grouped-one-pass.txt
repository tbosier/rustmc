# Grouped Normal terms from per-group statistics: gradient, build and rebind, many-term, plain-family and whole-fit timings
# Model name: AMD Ryzen 9 5900X 12-Core Processor; Linux 6.18.58-1-lts; rustc 1.89.0; 2026-10-27
# Base: main at a1e36fc (#48's fused loops). This branch: 15ac728 (perf/grouped-one-pass).
# The base build is `git archive a1e36fc` built in a scratch directory with its own target
# directory and its own wheel. Its rust_core/examples/indexed_gradient_cost.rs was replaced by
# this branch's copy, which adds the build and rebind columns and uses only public API that
# main has, so both builds time the same program. grouped_scaling.rs, gradient_cost.rs and
# benchmarks/grouped_normal_fits.py are unchanged between the two revisions.
# Every run held /tmp/claude-1000/bench.lock and started at a 1-minute load below 1.5 (printed
# per run, 1.12 to 1.49). Builds alternate, and every group of runs was repeated with builds
# and shapes in the reverse order ("order B"). Commands, per build:
#   target/release/examples/indexed_gradient_cost 500:20 5000:100 200:5000   (and reversed)
#   target/release/examples/grouped_scaling 10 100 1000                       (and reversed)
#   target/release/examples/gradient_cost 500 ; gradient_cost 5000
#   PYTHONPATH=<build>/.pybuild python benchmarks/grouped_normal_fits.py <build> ROWS GROUPS
# Other processes shared the machine during the session (the 1-minute load reached several
# hundred an hour before these runs); the load gate is the only control for that.
#
# Summary (four runs per build: two in order A, two in order B; ranges are min to max)
#   gradient, 500 rows x 20 groups     base 2.95-3.03 us    this branch 0.43-0.52 us   paired cut 82.6-85.7%
#   gradient, 5000 rows x 100 groups   base 26.27-27.00 us  this branch 1.16-1.19 us   paired cut 95.5-95.6%
#   gradient, 200 rows x 5000 groups   base 19.22-19.37 us  this branch 18.36-18.43 us paired cut 4.5-5.1%;
#       base declines fusion here (0 fused passes), this branch fuses it (18000); the rest of the
#       gradient is the 5,000-effect prior and gradient zeroing, which this change does not touch
#   building an evaluator (Evaluator::new, median of 9 batches):
#       500 x 20     base 5.0-5.8 us    this branch 11.9-12.7 us
#       5000 x 100   base 39.8-84.3 us  this branch 98.6-145.5 us (both builds bimodal across runs)
#       200 x 5000   base 87.3-89.8 us  this branch 100.5-102.2 us
#   rebinding the same data (Evaluator::rebind, median of 9 batches):
#       500 x 20     base 4.1-4.7 us    this branch 10.0-10.3 us
#       5000 x 100   base 34.5-39.7 us  this branch 90.0-92.3 us
#       200 x 5000   base 84.7-87.4 us  this branch 96.7-98.0 us
#   so at 5,000 rows a build or rebind costs about 55 us more, the price of about two gradients
#   on base or fifty on this branch
#   many grouped terms (20 rows, 5 groups each; per gradient):
#       10 terms     base 2.69-2.94 us      this branch 1.44-1.45 us
#       100 terms    base 26.03-28.94 us    this branch 12.90-13.17 us
#       1000 terms   base 276.6-316.9 us    this branch 143.0-146.6 us   (0.143-0.147 us per term)
#   many plain terms (no candidate chain): 10, 100 and 1000 terms within run-to-run spread
#       (1000 terms: base 84.6-94.4 us, this branch 83.9-85.2 us)
#   plain families (gradient_cost.rs, no grouped term; 50 shapes, 4 pairs each): paired changes
#       from -21.8% to +12.4%, 172 of 200 within 5%. Twelve shapes were slower in all four pairs,
#       by 0.2% to 9.7%: at 500 rows Bernoulli-logit at 2, 8 and 32 columns (0.6% to 6.5%) and
#       Normal with an inferred scale at 128 (6.3% to 9.7%); at 5,000 rows Bernoulli-logit at 2,
#       8, 32 and 128, Normal at 128, Normal with an inferred scale at 512, and Poisson-log at 32
#       and 128 (0.2% to 5.4%). Ten were faster in all four, by 0.2% to 21.8%. On a graph without
#       a grouped chain this branch runs the same operations as base plus one relaxed atomic
#       load per forward pass, which points to code layout, but this data cannot rule out a
#       real cost of a few percent on those shapes.
#   fit, 500 x 20 (median of 3 datasets)     base 0.681-0.700 s  this branch 0.195-0.210 s  cut 70.0-71.7%
#   fit, 5000 x 100 (median of 3 datasets)   base 5.289-5.387 s  this branch 0.355-0.369 s  cut 93.0-93.4%
#   leapfrog steps over the 3 datasets differ, since the draws differ: 578,425 (base) and 568,174
#   (this branch) at 500 x 20; 582,531 and 595,383 at 5000 x 100. Each fused run ran at least one
#   fused reverse pass per step (568,528 and 595,750). Wall time per leapfrog step at 5000 x 100
#   is 27.7-28.8 us on base and 1.84-1.92 us on this branch, including the sampler's own work;
#   the 2026-10-27 head-to-head study measured nutpie at about 11 us per step on this model
#   (sampling seconds per step, its own harness, not rerun here). ESS was not measured in
#   these fits.
#
# Fits: rustmc.ModelBuilder, mu ~ N(0, 5), tau ~ HalfNormal(1), z ~ N(0, 1) per group,
# sigma ~ HalfNormal(1), y ~ Normal(mu + tau * z["group"], sigma); 4 chains of 1000 warmup
# and 1000 draws on one thread; 3 datasets drawn by the script, seeds 0 to 2.
