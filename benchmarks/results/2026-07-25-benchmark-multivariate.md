## Model / workload

- Script: `examples/benchmark_multivariate.py`
- Model: `y = X @ beta + Normal(0, sigma)`, 10 estimated parameters, N=100,000 observations.
- True/simulated values: `beta_true = linspace(0.5, 3.0, 10)`, `true_sigma = 0.5`.
- Estimated vs. fixed: all 10 betas are estimated on every engine; `sigma = 0.5` (the true
  simulated noise) is fixed/known on every engine — same parameter count (10) everywhere.
- Chains: 8 (all engines). Warmup: 1000 (all engines). Draws: 2000 (all engines).
- Seed: 42, explicit on every engine (**corrected**: the original version of this script ran
  PyMC with no explicit `random_seed` and its unspecified default `nuts_sampler`).
- Threads/processes: rustmc's Rayon default pool for 8 chains; PyMC/nutpie use `cores=8`
  (8 worker processes).

## Result

- Raw output log: see `benchmarks/results/benchmark_multivariate.py.log` (generated by
  `python examples/run_benchmarks.py`).
- Honest conclusion: rustmc is genuinely 5.2x faster than PyMC's default NUTS sampler and
  roughly at parity (1.1x faster) with PyMC+nutpie on this 10-parameter, 100k-observation,
  8-chain workload, once chains/warmup/draws/seed are matched and sigma is fixed
  identically on both sides. This is a real win, unlike the 500-parameter case
  (`benchmark_vs_pymc.py`), where rustmc loses. As in the other benchmarks, rustmc
  produced a nonzero divergence count (67) where both PyMC backends produced 0 on the
  identical model/data/seed — worth investigating, not something to omit because the
  headline speed number looks good.
- This result is close to an earlier, unverified README claim of "72s / 5.3x speedup vs.
  PyMC (383s)". The earlier claim did not control PyMC's seed or NUTS backend, so the
  similarity here looks like a coincidence of this specific workload rather than
  confirmation the earlier methodology was fine — the 500-parameter and batch-SKU
  benchmarks show the same "PyMC default vs. nutpie" methodology gap can flip or shrink
  the story substantially, so each workload still needed independent verification.

## Reproduction

```bash
python examples/benchmark_multivariate.py
# or:
python examples/run_benchmarks.py --only benchmark_multivariate.py
```

Runtime note: the PyMC default-NUTS backend takes ~6 minutes on the reference hardware
above; this is the slowest single leg of the suite.
